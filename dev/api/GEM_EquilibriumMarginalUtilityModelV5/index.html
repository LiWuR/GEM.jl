GEM.EquilibriumMarginalUtilityModelV5

GEM.EquilibriumMarginalUtilityModelV5 — Module
EquilibriumMarginalUtilityModelV5

Define consumer equilibrium conditions from marginal utility, local prices, net supply, and optional observed equilibrium variables.

source
GEM.EquilibriumMarginalUtilityModelV5.MarginalUtilityConsumerConditions — Type
MarginalUtilityConsumerConditions(
    marginal_utility_function,
    demand_variable_positions,
    demand_price_positions,
    multiplier_variable_position,
)

Define consumer complementarity conditions from marginal utility and a budget constraint. The marginal-utility function may accept either demand or (demand, observed_values) and must return one value per demand variable.

source
GEM.EquilibriumMarginalUtilityModelV5.evaluate_marginal_utility — Method
evaluate_marginal_utility(rule, demand[, observed_values])

Evaluate the marginal-utility function stored in rule.

The stored function may implement either MU(demand) or MU(demand, observed_values). If the two-argument form is applicable, it is preferred so an agent that declares observed variables can use them directly.
